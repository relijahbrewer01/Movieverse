# Source assessment

Reviewed 2026-11-17 against primary source documentation. Approved entries are limited to the stated use. The shipped release contains original fixtures only.

| Source | Access and fields | Rights, attribution, open questions | Decision |
| --- | --- | --- | --- |
| Movieverse fixtures | Tracked JSON with invented titles, years, genre tags and formats | Original records and generated sample dedicated under CC0 1.0. UI marks them fictional. | **Approved** for the demo |
| Wikidata | Official entity dumps, APIs and targeted SPARQL. Candidate QIDs, titles, genres, classification, language, country, dates, credits and statement references. | Structured entity data is CC0. Preserve statement IDs and provenance. Use bounded queries for exploration and pinned entity dumps for bulk work. Review query etiquette and classification and qualifier coverage before running ingestion. [Licensing](https://www.wikidata.org/wiki/Wikidata:Licensing) · [Data access](https://www.wikidata.org/wiki/Wikidata:Data_access) · [Dumps](https://www.wikidata.org/wiki/Wikidata:Database_download) | **Approved** for a future bounded structured-data audit |
| Wikipedia | Manual verification and potential aliases via official API/dumps | Article text generally CC BY-SA with attribution and share-alike for covered reuse. Exclude plot text from the open core and retain links for manual evidence. [Terms](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) | **Deferred** |
| Wikimedia Commons | Official API or file pages, candidate imagery | License, creator credit, license link and other rights vary per file. Record the specific requirements before publishing an asset. [Licensing](https://commons.wikimedia.org/wiki/Commons:Licensing) | **Deferred** |
| TMDB | Registered API for metadata, images, keywords and credits | Developer terms require attribution and limit use to noncommercial purposes. Verify logo/notice, storage, redistribution, model use, and impact of donations before adopting. [API FAQ](https://developer.themoviedb.org/docs/faq) | **Deferred** |
| Open Film Database (ofdb.cc) | Public JSON:API for films, original titles, credits and external references | Publisher describes an open database. Exact database, record/media scope and obligations (including possible ODbL terms) remain unverified. Confirm license and compatibility before mixing data. [Publisher](https://www.ofdb.cc/) · [API](https://www.ofdb.cc/api-info) | **Deferred** |
| Cadrame | Public JSON API for identities, claims, revisions and sources | Publisher states CC0 1.0 for data. Assess coverage, statement accuracy, and stable snapshots and mappings. Follow external references as evidence. [Data and license](https://cadrame.org/data) | **Deferred** |
| MovieLens | Official downloads for ratings, tags and links | Conditions vary by release. Latest Small permits research and redistribution under the same terms, requires acknowledgment in publications, and requires permission for revenue-bearing use. Confirm that a public atlas and its derived geometry qualify before integrating. [Dataset terms guidance](https://grouplens.org/datasets/movielens/) · [Latest Small license](https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html) | **Blocked** for public catalog ingestion pending clearance |
| Letterboxd | User-initiated account export. Approved API access may be separate. | Confirm ZIP/CSV schemas with authorized test exports. Process locally, retain user controls, and verify API access and reuse terms before any live sync. [Account export](https://letterboxd.com/user/exportdata/) · [API access](https://letterboxd.com/api-beta/access/) | **Deferred** |
| Trakt | Authorized API for personal history, lists, and ratings | Policy permits compliant integrations and restricts bulk harvest and unauthorized dataset redistribution. Check authentication, caching, and display obligations at integration time. [API use policy](https://developer.trakt.tv/docs/api-use-policy) | **Deferred** for personal integration |
| Grokipedia | Possible manual research lead | Site access and a specific machine-ingestion license remain unverified. Find independent primary evidence for individual facts. [Publisher terms](https://x.ai/legal/terms-of-service) | **Blocked** for automated ingestion |
| IMDb | Official downloadable title/ID/credit subsets | Published datasets are offered for personal and noncommercial use subject to terms. Require independent clearance before redistributing data. Consider verified IDs from separately approved sources. [Dataset terms](https://developer.imdb.com/non-commercial-datasets/) | **Blocked** for public dataset redistribution pending clearance |

Before adding a source, record the reviewed scope and date, approved fields, attribution, retention/redistribution limits, and how to reproduce the source snapshot. Track approved structured facts, separately licensed assets, and private user records independently.
