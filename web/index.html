Start Movieverse

For a one-click preview, select the index.html in the repository root and choose Open in Integrated Browser.

Movieverse runs through Vite. From the repository root, run these commands in a terminal:

cd web
pnpm install --frozen-lockfile
pnpm dev

Open the local URL printed in the terminal. Use Node.js 24 or newer and pnpm 11.25.0.
