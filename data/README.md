# Data

Run `python -m pipeline.src.catalog` from the repository root to rebuild the tracked `sample/` artifacts. Use `--output <directory>` to check a separate output. The manifest gives the revision, count, projection version and associated file names.

The original fictional `pipeline/fixtures/films.json` and generated `data/sample/` are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), to the extent permitted by law. The dedication applies to the fixture data and its outputs. See [source decisions](../docs/DATA_SOURCES.md) before adding external data. Keep credentials, private exports and raw external dumps out of Git.
